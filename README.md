# Sales Management System
*Created: 2019-12-19*

A desktop **sales management** application built during an **Object Analysis and Design (OAD)** course.

## Overview

The project models a sales management workflow as a NetBeans Java application. Alongside the source code, the repository includes analysis and design PDF diagrams documenting the system's structure, use cases, and development process.

## Repository Structure

```
├── src/            # NetBeans project source code
└── docs/           # Analysis & design PDF diagrams
```

## Features

- Sales transactions management
- OAD-style use-case and design documentation

## Tech Stack

Java, NetBeans, Object-Oriented Analysis and Design.

## Status

Completed university project.
